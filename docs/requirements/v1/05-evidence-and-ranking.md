# V1-05 证据与潜客排序【已确认】

> 状态：已确认  
> 版本：V1

## 1. 核心原则

潜客“准入”和“排序”分开：
- 准入：决定企业能否进入可用潜客池；
- 排序：决定对于某个物流产品，业务员应该优先联系谁。

第一版不使用无法解释的 0～100 黑盒 Match Score 作为核心产品表达。系统保存证据并动态排序，用户侧展示推荐理由。

## 2. 统一 Evidence 模型

此前讨论的 ExportEvidence 与 RelevanceEvidence 底层统一为 Evidence：

```text
Evidence
- id
- prospect_id
- product_id?       # 可空
- type
- description
- source_url
- found_at
- created_at
```

`product_id = null` 表示企业级证据，例如“该企业具有出口经营”；有 product_id 表示针对某个物流产品的相关性/竞争性证据。

Evidence 必须保留原始来源和发现时间，不能只保存 `is_exporter=true` 或 `match_score=87` 而丢失判断依据。

## 3. 企业级 Evidence 示例

- `export_business`：官网明确有 Overseas Market
- `international_b2b`：国际 B2B 中国供应商
- `export_exhibition`：出口型展会参展企业
- `trade_record`：存在可靠出口贸易记录

## 4. 产品级 Evidence 示例

- `destination_country`：官网市场明确包含 Venezuela
- `destination_region`：主营 Latin America / South America
- `transport_mode`：业务包含 Ocean Freight
- `product_category_relation`：主营产品与目的国进口需求有数据依据的相关性
- `same_route_supplier`：同行公开宣传同目的国一手庄家/专线强供给能力

Evidence type 后续可扩展，但不应为了枚举完整而一次性穷举所有业务词。

## 5. 国内同行排序规则

同行排序核心不是“同线路越强越好”，而是 **有货源能力 + 与我资源互补**。

### 优先方向
1. 国际货代、有海运/国际业务能力、有客户来源能力，但未发现目标线路强供给能力；
2. 相邻线路/区域相关，例如做拉美/南美其他国家或相关运输业务，但没有明确目标线路庄家能力；
3. 普通国际货代，有可触达联系方式。

### 降低优先级但不排除
如果同行明确宣传与当前产品高度重合的强供给能力，例如：
- 一手庄家
- 一级代理
- 船东直签
- 自营清关/海外仓
- 包板/包舱
- 合约价/同行底价
- 全国收货
- 目标国家专线庄家

则记录 `same_route_supplier` 等 Evidence，降低开发优先级，但不删除。同行之间仍可能存在旺季舱位、特殊货、目的港资源等合作可能。

## 6. 出口货主排序规则

正向证据优先级：
1. 真实目的国出口事实（考虑新鲜度）
2. 明确目的国市场关系
3. 目的区域关系
4. 有数据依据的主营产品/目的国需求相关性
5. 普通出口企业

没有公开目的国信息不代表不是潜客，不作为硬排除条件。

## 7. 联系方式可操作性

最终业务员列表还需综合 Contact / ContactPoint 的可操作性：
- 具体业务联系人通常优于只有公司级通用联系方式；
- 目标职位（外贸、国际业务、物流/供应链等）可以提高实际触达优先级；
- 手机/电话/邮箱的实际可用性参与动态排序；
- 产品相关性与联系方式质量分别保留底层事实，不混成企业永久属性。

## 8. 用户侧表达

不要求业务员理解 Evidence 枚举或技术分值。列表直接展示推荐理由，并允许查看来源依据。

示例：

> 广州 ABC 汽配有限公司  
> ✓ 近期存在委内瑞拉方向出口证据  
> ✓ 主营汽车零配件  
> ✓ 找到外贸经理手机号

同行示例：

> 上海 XYZ 国际物流  
> ✓ 国际海运同行  
> ✓ 主营南美相关线路  
> ✓ 未发现委内瑞拉专线庄家宣传  
> ✓ 找到业务经理手机号
