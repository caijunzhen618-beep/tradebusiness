# V1-02 潜在客户与联系方式【已确认】

> 状态：已确认  
> 版本：V1  
> 当前范围：国内拓客；当前确认的客户类型为国内同行货代与出口货主。

## 1. Prospect 定义

**潜在客户 Prospect = 企业本身，不是具体联系人。**

例如“深圳 ABC 国际物流有限公司”是一个 Prospect。该公司下面可以有多个具体联系人，也可以只有公司电话或通用邮箱。

同一家企业在全系统保持唯一。即使它同时被“委内瑞拉海运”和“南非海运”等不同获客计划发现，也不应重复创建企业记录。

## 2. Prospect 基础字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | ID | 企业唯一标识 |
| company_name | 文本 | 公司名称 |
| company_type | 枚举 | freight_forwarder / exporter |
| province | 文本/行政区字典 | 省 |
| city | 文本/行政区字典 | 市 |
| address | 文本，可空 | 企业地址 |
| website | URL，可空 | 企业官网 |
| business_description | 文本，可空 | 公开资料中获得的主营业务描述 |
| created_at | 时间 | 系统字段 |
| updated_at | 时间 | 系统字段 |

### company_type 第一版
- `freight_forwarder`：国内同行货代
- `exporter`：出口货主

“出口货主”描述的是货代真正关心的业务属性：企业有货需要从中国出口。它可以包含工厂、工贸一体企业、外贸公司以及其他实际出口企业。第一版不再把“工厂”作为与出口货主并列的顶层获客类型。

## 3. 不直接放在 Prospect 上的数据

### 联系方式
一家公司可能有多个电话、多个邮箱、多个联系人，因此不使用 `phone1 / phone2 / email1 / email2` 这类平铺字段。

### 产品相关性
同一家公司对不同物流产品的相关性不同，不在 Prospect 上存永久 `match_score`。

### 出口/产品相关证据
“为什么认为它是出口货主”“为什么认为它与委内瑞拉海运相关”等信息使用 Evidence 保存来源和依据，不只保存一个黑盒结论。

## 4. Contact：具体联系人

```text
Contact
- id
- prospect_id
- name
- title
- created_at
- updated_at
```

Contact 表示企业中的具体个人。`title` 后续可用于业务员列表的联系方式可操作性排序，例如外贸经理、国际业务负责人、物流/供应链负责人等通常比公司总机更适合优先触达。

## 5. ContactPoint：可触达联系方式

```text
ContactPoint
- id
- prospect_id
- contact_id?      # 可空；为空表示公司级联系方式
- type
- value
- source_url
- found_at
- is_valid?        # null / true / false
- created_at
- updated_at
```

### type 第一版
- `mobile`：手机
- `phone`：公司电话/固定电话
- `email`：邮箱

`contact_id = null` 表示公司级联系方式，例如总机、`sales@abc.com`、`info@abc.com`；有 contact_id 表示属于具体个人。

## 6. 微信处理原则

微信暂不作为第一版核心联系方式类型。“手机号可能可以添加微信”只是操作建议，不能在没有明确公开证据时把手机号复制成微信号事实。

## 7. 来源与数据质量

每条 ContactPoint 保留：
- `source_url`
- `found_at`

第一版在入池前执行确定性数据质量校验，至少识别：
- 电话/手机号明显格式错误
- 明显测试或占位号码
- 明显重复数字/模板号码
- Email 基本格式错误
- 明显测试/占位邮箱或域名

公开页面上出现一个字符串不等于它就是可用联系方式。明显无效的 ContactPoint 不计入“可用潜客”判断。

## 8. 联系方式有效性

采用 nullable Boolean：
- `null`：尚未由业务反馈确认
- `true`：已确认有效
- `false`：已确认无效

业务员确认空号、错误邮箱等情况时不删除历史数据，而是标记无效，以避免再次推荐并保留数据源质量证据。

## 9. 可用潜客定义

### 国内同行货代

**国际货代企业 + 至少一种通过基础质量校验的可触达联系方式。**

### 出口货主

**企业具有足够出口证据/明显出口经营信号 + 至少一种通过基础质量校验的可触达联系方式。**

第一版以下任意一种均算可触达：手机、公司电话、个人邮箱、公司通用邮箱。

只有公司名称、地址、官网但没有上述联系方式的企业，不计入可用潜客数量。

不额外存储 `is_usable`，通过企业类型、Evidence 与 ContactPoint 实时判断。

## 10. 潜客池数量

“潜客池目标 1000”表示目标为 **1000 家可联系的企业**，不是 1000 个联系人，也不是 1000 条搜索结果。一家公司即使有多个联系人，仍然只计算为一个 Prospect。
